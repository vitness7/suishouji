# App 品牌图标替换

- 用户问题：应用内页眉和系统启动图标仍使用旧版蓝绿收据标志，与最新 OneLedger 品牌稿不一致。
- 目标：全软件统一使用用户在 2026-07-27 提供的“折叠数字 1 + 账页”标志。
- 包含：
  - 四个主页面页眉中的彩色品牌标志。
  - Android 自适应启动图标及传统、圆形兼容图标。
  - Android 13 及以上主题图标使用的单色标志。
  - 受影响的截图回归基准和 README 预览图。
- 不包含：
  - 重做应用主题色、页面布局或底部导航图标。
  - 修改应用名称或包名。
- 视觉规则：
  - 彩色图标使用深海军蓝底、白色折叠数字 1/账页和黄色中间强调线。
  - 单色图标保留完整轮廓与三条账页线，由系统统一着色。
  - 标志不得拉伸、旋转、增加文字或叠加其他符号。
  - 自适应图标主体必须位于 Android 安全区内，避免圆形或圆角矩形遮罩裁切。
- 无障碍：应用内品牌图提供“OneLedger”语义；系统启动图标继续使用应用名称。
- 验收：
  - Given 用户从桌面启动应用，When 启动器显示普通、圆形或自适应图标，Then 均为新版标志。
  - Given Android 13 主题图标已启用，When 系统对图标着色，Then 标志轮廓完整可辨。
  - Given 用户进入账本、资产、存钱或统计页，When 查看标题栏，Then 显示同一新版彩色标志。
  - Given 执行截图回归，When 渲染四个主页面，Then 只有预期的品牌标志区域发生变化。
