# App 图标、启动页与快速记账入口

- 用户问题：App Icon 与最新白底品牌稿不一致，标志视觉重心偏低；启动时缺少统一品牌画面，快速记账按钮混入青绿色后与主蓝色体系不够统一。
- 目标：使用用户在 2026-07-27 提供的白底“折叠数字 1 + 账页”标志，保证系统图标与启动页视觉居中，并让账本快速记账入口使用有层次的品牌蓝。
- 包含：
  - Android 自适应启动图标及传统、圆形兼容图标。
  - Android 13 及以上主题图标使用的单色标志。
  - Android 23+ SplashScreen 兼容实现、浅色白底和深色模式资源。
  - 账本页右下角快速记账按钮。
  - 页面页眉移除重复的品牌图标和 `ONELEDGER`，仅保留对应中文标题。
  - 方形品牌母版、相关文档和受影响的截图回归基准。
- 不包含：
  - 重做页面布局、底部导航图标或添加额外启动页 Activity。
  - 修改应用名称或包名。
- 视觉规则：
  - 彩色图标使用纯白底、深蓝数字 `1`、炭黑账页与黄色中间强调线。
  - 单色图标保留完整轮廓与三条账页线，由系统统一着色。
  - 标志不得拉伸、旋转、增加文字或叠加其他符号。
  - 标志水平、垂直中心分别锁定在 `54±0.5`；主体保持在 Android 自适应图标安全区内。
  - 启动页不人为延长停留时间，浅色使用纯白背景，深色使用 `#0B0D10` 并替换为高对比标志。
  - 快速记账按钮只使用浅蓝、品牌蓝和深蓝；顶部高光、底部暗部和边框共同形成材质，不添加装饰圆点。
  - 品牌标志集中用于 App Icon 与启动页；四个主页面采用系统中文无衬线 `28sp / 34sp SemiBold` 标题，详情页采用“返回键 + 中文标题”。
- 无障碍：系统启动图标继续使用应用名称；快速记账按钮保留“快速记账”语义及至少 48dp 触控区域。
- 验收：
  - Given 用户从桌面查看应用，When 启动器显示普通、圆形或自适应图标，Then 均为白底、居中的新版标志且没有遮罩裁切。
  - Given Android 13 主题图标已启用，When 系统对图标着色，Then 标志轮廓完整可辨。
  - Given 系统为浅色或深色模式，When 冷启动应用，Then 启动页背景、标志对比度正确且标志位于屏幕中心。
  - Given 用户按下快速记账按钮，Then 蓝色按钮即时缩小，释放后无过冲地恢复，不出现青绿色或装饰噪点。
  - Given 用户进入任意主页面或详情页，When 查看左上页眉，Then 不出现品牌图标或 `ONELEDGER`，只显示对应中文标题及必要的返回入口。
  - Given 执行截图回归，When 渲染账本页，Then 只有预期的快速记账按钮区域发生变化。
