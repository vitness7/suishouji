# Quick Add 分类与转账展示改造

> 分支：`feature/quick-add-category-transfer-ui`｜级别：L2 UI 功能｜日期：2026-07-27

## 用户问题

Quick Add 的支出/收入分类缺少统一的线性图标和二级分类展示；转账仍复用分类式网格，账户选择缺少清晰的来源、去向和余额信息。

## 目标

- 支出、收入使用同一套线性图标、圆形浅灰默认容器和明确的红/绿选中语义。
- 读取现有 `CategoryEntity.parentId` 展示二级分类，一次只展开一个主分类。
- 转账使用转出卡片、交换操作、转入卡片和黄色金额语义。
- 转出/转入卡片打开账户选择底部面板，支持搜索、余额展示和“不选择账户”。
- 保持 Quick Add 的金额、表达式、键盘、IME、备注与保存逻辑原样。

## 包含

- Quick Add 展示层的分类树构建与图标映射。
- 主分类展开/收起以及二级分类选择展示。
- 转账主体、转账快捷标签和账户选择面板。
- 将 ViewModel 已有的 `accountBalances` 只读传给 Quick Add。
- 纯展示辅助函数的单元测试，以及支出、二级分类、收入、转账和账户面板的截图回归。

## 不包含

- 新增或迁移持久化分类。
- 账户新增、编辑或数据结构修改。
- Room、DAO、Repository、ViewModel 对外状态修改。
- `AmountCalculatorState`、`KeyboardMode`、IME/自定义键盘交接、备注、保存和导航逻辑修改。
- 优惠、图片、标签、手续费的业务录入能力；本期仅建立转账展示入口。

## 页面状态

- 默认：支出主分类，无二级分类展开。
- 选中：支出红、收入绿、转账黄；图标与主操作保持同一语义。
- 展开：点击带省略标记的主分类，在其所在行下方展开二级面板。
- 收起：再次点击同一主分类；点击另一带子分类主项时直接切换面板。
- 空分类：显示“暂无可用分类”。
- 空账户：账户面板只显示“不选择账户”。
- 搜索无结果：保留“不选择账户”，并显示“没有匹配的账户”。
- 禁用：与另一端已选账户相同的列表项不可选择。

## 数据影响

无 schema、DAO、Repository 或持久化数据变化。分类树完全由现有 `CategoryEntity.parentId` 派生；账户余额来自现有 `OneLedgerUiState.accountBalances`。

## 动效与无障碍

- 点击反馈沿用 `PressableSurface`，在按下时即时出现。
- 二级面板从对应主分类行下方展开并沿原路径收起，不弹跳。
- 模式切换沿用现有短淡化，不改变键盘承载区。
- 所有分类、交换、关闭和账户项提供语义描述；颜色不是唯一信息来源。

## 验收条件

1. Given 支出模式，When 选择分类，Then 图标容器为支出红、图标为白色、金额和完成按钮仍为支出红。
2. Given 收入模式，When 选择分类，Then对应语义为收入绿。
3. Given 转账模式，Then 不显示分类网格，显示转出/转入卡片与黄色金额/完成按钮。
4. Given 主分类存在子分类，When 连续点击同一主分类，Then 展开、收起、再展开。
5. Given 一个主分类已展开，When 点击另一个带子分类主项，Then 只显示后者的二级面板。
6. Given 主分类没有子分类，When 点击，Then只选择分类且不改变当前展开面板。
7. Given 无账户，When 打开账户面板，Then 只显示“不选择账户”。
8. Given 有账户，When 打开账户面板，Then 同时显示“不选择账户”和账户名称、副标题、余额。
9. Given 选择了转出账户，When 打开转入账户面板，Then 同一账户项不可再次选择。
10. 构建、单元测试、Lint、截图测试和 Android 测试源码编译通过。
