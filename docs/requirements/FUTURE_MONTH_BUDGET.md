# 未来月份预算

## 用户问题

用户需要在当月到来之前规划总预算和分类预算，并在账本首页直接查看该月的预算摘要。

## 范围

- 账本页的月份导航可连续进入未来月份，不设置产品层面的未来月份上限。
- 未来月份没有账单时保持空状态，预算、已用和可用金额均按该月数据计算。
- 点击任意月份的预算摘要，预算详情必须打开同一个月份。
- 预算详情可继续前后切换月份，并为所选月份设置总预算或分类预算。
- 每个月份的预算独立保存，修改未来月份不能覆盖当月或其他月份。

本需求不包含周期预算自动复制、预算提醒和云同步。

## 数据规则

- 预算仍以 `periodStart` 和 `periodEnd` 标识月份，不引入数据库迁移。
- 保存时使用预算详情当前显示的 `MonthWindow`，Repository 按账本、周期、分类唯一更新。
- 未来月份的剩余日均使用该月完整自然日数；历史月份保持 0 天。

## 验收条件

- Given 账本页显示当月，When 连续点击“下个月”，Then 可以进入任意未来月份。
- Given 账本页显示未来月份，When 点击预算摘要，Then 预算详情显示相同年月。
- Given 在未来月份保存总预算，When 返回账本页，Then 该月摘要立即显示新预算。
- Given 在未来月份保存分类预算，When 切换到其他月份再返回，Then 原预算仍归属于该未来月份。
- Given 未来月份没有账单，Then 已用金额为 0，页面不复用当月账单或预算。
